# ParkAhead Data

Place datasets here:

- `raw/birmingham_parking.csv` - Birmingham parking dataset (SystemCodeNumber, Capacity, Occupancy, LastUpdated)
- `raw/klcc_parking.txt` - KLCC parking dataset (semicolon separated)
- `raw/pklot_sample.csv` - PKLot sample (image data; not used for time-series prediction)

The app will load and clean data from raw/ for training and prediction.
